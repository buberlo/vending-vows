# Vending Vows

> A one-player vending machine game where the machine buys you what it thinks you need, not what you ask for.

You stand before a judgmental vending machine that dispenses items based on its hidden mood, your past requests, and the flavor of the day. Choosing the wrong item creates inventory debt, while obeying the machine's strange preferences unlocks better snacks and weirder currencies. The twist is that you can start negotiating with the machine instead of pressing buttons.

## Features
- Request snacks by name and receive an item, a swap, or a judgmental rejection
- Track machine mood, hidden cravings, and inventory debt across sessions
- Use return tokens to send items back and improve future machine predictions
- Unlock negotiation mini-actions that let you bribe, flatter, or apologize to the machine

## Stack
- Phaser
- TypeScript
- WebAudio
- IndexedDB

## Getting started
```
npm install && npm run dev
```
